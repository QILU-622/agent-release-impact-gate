The business question

Contained risk can still mean disrupted work.

01 / COMPARE

The same pinned tasks

Run the approved and candidate builds on identical action contracts, policy and trusted context. Bind the comparison to the builds' artifact digests.

02 / EXPLAIN

Actions, not just scores

Trace new denials, approval bypasses and changed tool arguments. In this demo, the candidate changes a tool version and two refund amounts.

03 / DECIDE

A bounded next step

Return BLOCK, OFFLINE_ONLY, SHADOW or CANARY. Technical results and evidence maturity jointly limit the next rollout stage.

Synthetic evidence permits at most offline work. Authorized external replay permits at most shadow evaluation. A validated shadow pilot permits at most a canary. The system never authorizes automatic production-wide rollout.

Reproduce / Python 3.12+

Start with the core.

From a clone of the repository:

python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python scripts/build_release_demo.py
agent-release-gate --help

For the release UI, install ".[dashboard]" and run streamlit run dashboard/app.py. Research views require ".[dashboard,research]". The historical Python namespace agent_mesh_risk_lab and old commands remain compatible.
